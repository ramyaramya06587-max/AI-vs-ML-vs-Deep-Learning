# Task 10: AI vs ML vs Deep Learning

## Project Overview
This project explores the differences, relationships, and real-world applications of Artificial Intelligence (AI), Machine Learning (ML), and Deep Learning (DL). It includes a comparison table and a simple Python demonstration to explain the key concepts.

## Objectives
- Understand the concepts of AI, ML, and Deep Learning.
- Compare their definitions, techniques, and data requirements.
- Identify real-world applications of each technology.
- Understand the relationship between AI, ML, and DL.
- Demonstrate the concepts using Python.

## Technologies Used
- Python
- Jupyter Notebook
- Markdown

6. Relationship Between AI, ML, and Deep Learning
7. Real-World Applications
8. Conclusion
9. Interview Questions and Answers
10. Python Code Demonstration

## Python Demonstration
The Python program stores the definitions and examples of AI, ML, and Deep Learning in a dictionary and displays them using a loop.

## Key Learnings
- AI is the broader field of creating intelligent systems.
- Machine Learning is a subset of AI that learns patterns from data.
- Deep Learning is a subset of Machine Learning that uses multi-layer neural networks.
- These technologies have applications in automation, recommendations, image recognition, and many other areas.

## Conclusion
This project helped develop a clearer understanding of AI, ML, and Deep Learning, their differences, and their applications in real-world scenarios.
